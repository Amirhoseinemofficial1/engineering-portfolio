## Selected systems

### Fundamental Intelligence Brain

A multi-asset intelligence system for collecting material events, preserving evidence, separating fast ingestion from expensive analysis, and controlling adaptive models through validation and rollback gates.

**Work:** event ingestion, source normalization, impact routing, evidence-backed signals, stateful processing, deployment controls, and service observability.

### CEX Hunter v12

A token-event and centralized-exchange research platform designed around exact venue context, security gates, purged evaluation, and fail-closed model promotion.

**Work:** exchange integrations, structured market evidence, token safety, outcome labeling, calibration, professional signal documents, and controlled learning.

### NFT Hunter v10

A multi-chain NFT intelligence scanner that combines provider health, quality vetoes, wallet and collection evidence, explainable scoring, and verified outcome labels.

**Work:** provider orchestration, source reconciliation, data quality, feature engineering, model governance, and auditable decisions.

### GamePulse and GamePlus

Full-stack game discovery and community products built around Django APIs and modern React interfaces, with content workflows, profiles, groups, tournaments, and media-oriented experiences.

**Work:** product architecture, backend APIs, database models, responsive interfaces, administrative flows, and build/deployment engineering.

### Quantitative Research Systems

A family of market-data, signal, backtesting, order-book, execution, and multi-venue research systems. The public portfolio groups related experiments into canonical repositories instead of presenting every local snapshot as a separate project.

**Work:** data ingestion, timestamp alignment, rule mining, conservative outcome labeling, backtesting, risk controls, live signal matching, and exchange execution research.

### Persian Document Intelligence

A staged pipeline for Persian document ingestion, OCR reconstruction, semantic cleanup, corpus preparation, tokenizer research, and from-scratch language-model experiments.

**Work:** document forensics, text normalization, dataset lineage, validation, tokenizer experiments, retrieval, and domain-specific language tooling.

- Model changes earn promotion through evaluation, not intuition.
- Expensive intelligence is isolated from real-time ingestion.
- Historical records reflect the evidence available in the original files; imported work is not presented as personal authorship.
